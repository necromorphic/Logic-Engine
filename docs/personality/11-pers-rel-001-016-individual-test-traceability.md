## Boundary and closure rules

- Pure evaluator tests prove candidate semantics only; they do not prove Core persistence, authorization, consumer delivery, or event lifecycle behavior.
- Privileged admin-gated Core tests prove only the implemented privileged typed-operation slice; do not generalize them to NPC-authorized production paths.
- “Specified,” a synthetic fixture, a documentation crosswalk, or a passing unrelated CI run is not an executable test result for an untested row.
- Keep Issue #73 open while required-boundary cases are untested or contract-blocked. Assign the missing contract/test owners before claiming closure.
- Keep deterministic replay with pinned inputs/version separate from historical semantic re-evaluation, meaning-changing migration, and explicit incompatibility handling. Never silently substitute the latest World Pack for a missing historical version.
